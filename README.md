# 👨‍💻 Portfólio — Arthur Moura

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, projetos, conhecimentos técnicos e experiências nas áreas de **Desenvolvimento de Software** e **Suporte de TI / Help Desk**.

O projeto reúne em uma única página informações sobre minha formação em Ciência da Computação, tecnologias com as quais já trabalhei, projetos desenvolvidos e formas de contato.

## 🌐 Sobre o projeto

O portfólio foi desenvolvido utilizando **HTML, CSS e JavaScript puro**, com foco em uma interface moderna, responsiva e interativa.

A identidade visual foi inspirada em interfaces de perfis gamers, utilizando uma estética escura e tecnológica para apresentar informações profissionais e acadêmicas de uma forma diferente de um portfólio tradicional.

## ✨ Funcionalidades

- Apresentação pessoal e profissional
- Informações sobre minha formação acadêmica
- Experiência com Desenvolvimento e Suporte de TI
- Exibição de conhecimentos e tecnologias
- Cards para apresentação dos projetos
- Visualização de detalhes dos projetos
- Links diretos para repositórios no GitHub
- Links para GitHub e LinkedIn
- Apresentação de certificações
- Seção de contato
- Navegação responsiva
- Interface adaptada para dispositivos móveis

## 🚀 Projetos apresentados

### 📱 Teresina Tour

Aplicativo mobile desenvolvido como projeto de extensão universitária com o objetivo de facilitar o acesso a informações sobre pontos turísticos, culturais e eventos de Teresina - PI.

**Principais tecnologias:**

- React Native
- Expo
- TypeScript
- Supabase
- Git
- GitHub

### 💻 AFJCode

Projeto de startup de tecnologia desenvolvido em conjunto com outros dois integrantes, voltado para a criação de soluções digitais sob demanda.

A proposta envolve o desenvolvimento de:

- Sites
- Aplicações Web
- Aplicações Mobile
- Softwares personalizados

### 🎓 Projeto de Extensão — Tecnologia e Computação no Ensino Médio

Projeto universitário envolvendo o planejamento e realização de uma palestra para estudantes do ensino médio, apresentando diferentes áreas da Tecnologia da Informação e possibilidades de carreira.

Entre os assuntos abordados estão Desenvolvimento de Software, Redes, Segurança da Informação, Banco de Dados, Suporte Técnico, Inteligência Artificial e outras áreas da computação.
